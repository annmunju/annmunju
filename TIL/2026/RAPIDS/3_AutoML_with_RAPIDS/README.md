# RAPIDS 기반 AutoML 제작

- 첫 시작일 숙제
2. End-to-End GPU-based AutoML에서 중요하다고 생각한 것

1) 데이터 레이어

핵심은 GPU에서 만든 데이터가 중간에 불필요하게 CPU로 내려오지 않게 하는 것이라고 생각함

* GPU 친화적인 데이터 규약이 먼저 필요함
* 데이터 적재, 전처리, feature 생성 이후에도 포맷 변환이 최소화되어야 함
* cuDF, tensor 등 어떤 포맷을 표준으로 가져갈지 명확해야 함

2) 모델 실행 레이어

핵심은 여러 모델을 같은 구조에서 실행하고 비교할 수 있게 만드는 것이라고 생각함

* GPU 사용 가능한 모델부터 선제적으로 붙여보는 게 현실적이라고 봄
* 모델 내부 구현은 달라도 바깥에서는 같은 흐름으로 다뤄져야 함
* fit / predict / evaluate 같은 공통 인터페이스가 필요함
* 새 모델이 들어와도 전체 구조를 크게 바꾸지 않아야 함

3) 평가 레이어

학습만 GPU가 아니라, 평가까지 포함해서 반복 가능한 실험 구조를 만들기

* validation, metric 계산, leaderboard 생성도 같이 고려해야 함
* 학습용 데이터 생성이나 배치 구성도 실제로는 병목이 될 수 있어서 중요함
* 단순히 점수만 보는 게 아니라 어떤 조건에서 나온 결과인지 남길 수 있어야 함
* 결국 비교 가능한 실험 구조가 있어야 AutoML처럼 쓸 수 있다고 생각함

⸻

3. AutoML 개발 후 하고 싶은 것

* 먼저 GPU 기반 데이터 처리, 모델 실행, 평가가 이어지는 첫 버전을 제대로 만들고 싶음
* 이후에는 이를 시계열 문제로 확장해서 rolling validation / backtest까지 포함하는 구조로 가고 싶음
* 장기적으로는 전통 시계열 모델, 딥러닝, foundation model을 같은 기준으로 비교 가능한 형태로 발전시키고 싶음
